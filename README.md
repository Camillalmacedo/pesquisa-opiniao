✨ Para esta atividade em Python, utilizei as estruturas de **repetição** e **decisão** para fazer um programa que pede os dados de entrevistados, como **nome**, **idade** e **opinião sobre o serviço prestado**. Após 50 respostas obtidas, o programa mostra os resultados, indicando a quantidade de pessoas que escolheram as opções "Excelente" e "Ruim", conforme solicitado na atividade.

🖊️ Aprendemos no curso que a estrutura "for" é geralmente utilizada para situações em que o nú ero de repetições já é previamente estabelecido, por isso escolhi utilizá-la levando em consideração os 50 entrevistados.

📈 Ao longo do desenvolvimento da programação enfrentei alguns desafios, mas busquei solucionar todos os erros. Um erro inicial foi tentar coletar os dados antes do for, mas assim não seria possível coletar os dados de todos, pois as perguntas apareceriam apenas uma vez.
Também realizei alguns testes diminuindo o "range" para garantir o funcionamento do código e aprimorar quaisquer falhas.
